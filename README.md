## 文件说明

| 文件 | 内容 |
|---|---|
| `01_bonus.cpp` | 分段利润奖金计算 |
| `02_movie_rating.cpp` | 电影评分分类 |
| `03_palindrome.cpp` | 回文数判断 |
| `04_narcissistic.cpp` | 输出三位水仙花数 |
| `05_series_sum.cpp` | 数列 a + aa + aaa + ... 求和 |
| `06_multiplication_table.cpp` | 九九乘法表 |
| `07_rabbits.cpp` | 20个月兔子繁殖问题 |
| `08_monkey_peaches.cpp` | 猴子吃桃问题 |

## 测试示例

- 奖金计算：输入 `120000`，结果应为 `11500.00`。
- 电影评分：输入 `7`，结果应为“very good”。
- 回文数：输入 `12321`，结果应判定为回文数。
- 数列求和：输入 `3 2`，结果应为 `246`。
- 兔子问题：第 20 个月应为 `6765` 对、`13530` 只。
- 猴子吃桃：第一天共摘 `1534` 个。
