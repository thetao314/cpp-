# C++ Experiment 4: Arrays, Pointers and Strings

The experiment report is `高级语言程序设计实验报告_实验四_数组指针和字符串.docx`.

## Files

- `01_pointer_init_6_17.cpp`: initialize a pointer before dereferencing it
- `02_memory_management_6_18.cpp`: release dynamically allocated memory
- `03_simple_circle_6_20.cpp`: `SimpleCircle` with a pointer data member
- `04_count_letters_6_21.cpp`: count English letters in a sentence
- `05_reverse_string_6_22.cpp`: recursively reverse a string
- `06_pointer_safety_6_29.cpp`: demonstrate a type-safe correction for unsafe pointer conversion

## Build

Compile each file separately with C++11 support. For example:

```bash
g++ -std=c++11 03_simple_circle_6_20.cpp -o 03_simple_circle_6_20
```
